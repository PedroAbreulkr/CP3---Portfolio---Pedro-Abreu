# 💻 Portfólio — Pedro Abreu

Portfólio pessoal desenvolvido em **React.js (Vite)** com visual inspirado no **macOS**, apresentando meus projetos, informações de contato e links profissionais.

---

## ⚙️ Funcionalidades
- Menu com **rotas** (`react-router-dom`)
- **Lista de projetos** com props e rotas dinâmicas
- **Barra de busca** com renderização condicional
- **Formulário de contato** com exibição via `alert`
- **Rodapé** com ícones do `react-icons`

---

## 🧰 Tecnologias
React.js • Vite • React Router DOM • React Icons • HTML5 • CSS3

---

```bash
npm install
npm run dev
